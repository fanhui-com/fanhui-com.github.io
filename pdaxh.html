手机端 · 按批次卸货交互说明

字段还原（1:1）
扫码扫条码/箱号/托盘（无按钮，扫码枪自动触发）+ 模式下拉框（单台/托盘，默认单台，占按钮位）
单据卸货单据：erp单号xxxxx(上游发货单号xxx)· 扫码自动过滤，行号直接体现在单据框内
必填本次卸货数量*（已出库数量内联标签行体现，不能超出出库总数 100台）
必填卸货库位*（下拉单选，不含出库库位 / 在途库位）
必填卸货原因（下拉选择：客户订单退回（订单取消/客户拒收）/ 物流发货退回（货损、雨淋）/ 库内装车异常（货损、雨淋）/ 客户特殊要求更换）
带出物料属性卡：物料编码 / 物料名称 / 批次号 / 生产订单 / 原始托盘号 / 产地 / 生产日期
交互流程
  1. 扫码触发：无扫码按钮——扫码枪扫入后自动触发（演示按 Enter）；模式下拉框在原按钮位：单台（默认）扫单台条码/箱号、托盘扫托盘号，二者均用于定位批次，随后按批次点数卸货（托盘模式数量自动带出整板 48 台，可修改）；
  2. 扫码带出：扫入条码/箱号/托盘 → 自动校验在库状态（单台：库存已在库 → 黄色告警提示核对 / 托盘：托盘在库 ✓ + 托盘号在库！），自动带出物料属性卡，并自动过滤卸货单据：命中 1 条自动带出，命中多条弹出列表手工选 1 条（行号随单据带出）；
  3. 填写：确认单据/行号 → 录入本次卸货数量、下拉单选卸货库位（候选不含出库库位 / 在途库位）、下拉单选卸货原因（固定枚举四选一）；
    4. ④ 确认卸货：必填校验通过后点底部【确认卸货】（与打印合并为一键），弹出"卸货已完成·是否打印流程卡"确认窗——
    　· 点【打印流程卡】→ 进入"打印流程卡"窗口（新托盘拆分 + 新/旧托盘选择 + 模版 + 打印数量/页数）；
    　· 点【直接离开】→ 清空表单回到扫码初始态（卸货完成）； ⑤ 取消：清空当前录入，回到扫码初始态。
⚠ 扫码异常提示（三类）
① 扫入条码不属于当前卸货模式的管控范围 → "！该条码非按托盘批次卸货的，请用其他卸货模式"
　 触发：托盘模式下扫入单台条码/箱号；或条码非按批次卸货管控（演示：999 开头）
② 系统中未找到该条码的物料属性 → "！未找到条码相关物料属性"，需核对条码后重试
　 触发：演示输入 02（模拟数据匹配失败；输入 01 则匹配成功）
③ 该条码/箱号非按托盘点数出库 → "！此条码/箱号非按托盘点数出库，请走其他卸货模式扫码卸货"
　 触发：演示输入 03
三类异常均不带出物料属性与单据。
⚠ 散件入库物料重复批次属性入库提醒
扫入散件物料且批次属性与在库记录重复时，物料属性卡下方自动出现提醒条，需人工核对后方可继续卸货。
💡 原型可交互：在输入框输入 01 后按 Enter 模拟扫码枪（数据匹配成功）→ 物料属性卡逐项填充并青绿高亮闪动；输入 02 匹配失败（未找到物料属性）；输入 03 触发"此条码/箱号非按托盘点数出库"异常条；点【打印】一步打开合并后的打印流程卡弹窗 → 点【直接卸货】/【取消】体验其余分支。
