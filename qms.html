③ 生产日期：非必填，填写日期段；不填写表示不限日期；
④ 物料编码 / 物料名称：按条码、按托盘封存时由条码/托盘带出，按订单封存时系统带出；
⑤ 批次 / 生产订单号 / 状态 / 封存时间 / 封存人 / 封存原因 / 来源单号 / 解封人 / 解封时间 / 创建人 / 创建时间：系统带出；
⑥ 封存来源系统：qms（质量系统发起）/ wms（仓储系统发起）。
